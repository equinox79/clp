# clp

テキスト専用の高速クリップボード履歴ツール（Windows / macOS）。
ホットキーで即呼び出し、日本語の部分一致検索、選んだ項目をそのまま前のアプリへ貼り付けます。定型文（最大30個）にも対応。

- Tauri v2 + Rust + 素の HTML/JS（常駐メモリ・起動とも軽量）
- 履歴は SQLite に保存し、検索は全件をメモリ上で行う（数千件でも1ms未満）
- **Windows**: 動作確認済み
- **macOS**: 実装済みだが **Mac 実機では未検証**（下記「macOS について」参照）

## インストール

### Windows

[Releases](https://github.com/equinox79/clp/releases) から最新版をダウンロードします。

| ファイル | 内容 |
|---|---|
| `clp_x.y.z_x64-setup.exe` | インストーラ。ユーザー単位でインストールされ、管理者権限は不要です |
| `clp.exe` | インストール不要の単体版。好きなフォルダに置いて起動できます |

初回起動時に SmartScreen の警告が出たら、「詳細情報」→「実行」を選びます（コード署名をしていないためです）。
動作には WebView2 が必要です（Windows 11 には標準で入っています。Windows 10 は[こちら](https://developer.microsoft.com/microsoft-edge/webview2/)）。

### macOS

Releases から `clp_x.y.z_aarch64.dmg` をダウンロードし、開いて `clp.app` を「アプリケーション」へドラッグします。
初回は右クリック →「開く」で起動し、「プライバシーとセキュリティ → アクセシビリティ」で clp を許可してください。
詳細は「[macOS について](#macos-について)」を参照してください（Mac 版は未検証です）。

### ソースからビルド

「[ビルド](#ビルド)」を参照してください。

## アップデート

### アプリ内アップデート（インストーラ版 / macOS）

GitHub Releases に新しい版が公開されると、アプリ内からワンクリックで更新できます。

- 設定画面の「情報」→「更新を確認」→「今すぐ更新」。トレイメニューの「更新を確認…」からも開けます。
- 起動の少し後に、裏で新しい版を確認します（設定画面でオフにできます）。新しい版があるとトレイアイコンのツールチップに表示されます。
- ダウンロードした更新は署名を検証してからインストールされ、完了すると自動で再起動します。

**単体版（`clp.exe`）はアプリ内アップデートの対象外**です（更新するとインストーラ版が別に入ってしまいます）。単体版は下の手順で手動更新してください。

### 手動で更新する

新しい版を手動で入れ替える場合の手順です。

1. トレイアイコンを右クリック →「終了」で clp を終了します。
2. 新しい版を入れます。
   - **インストーラ版**: 新しいインストーラをそのまま実行します（上書きインストールされます）。
   - **単体版（`clp.exe`）**: 古い `clp.exe` を新しいものに置き換えます。
   - **macOS**: 新しい `clp.app` を「アプリケーション」に上書きコピーします。アクセシビリティの許可が外れていたら、再度許可してください。
3. clp を起動します。

履歴・設定・定型文は `%APPDATA%\clp\`（macOS は `~/Library/Application Support/clp/`）にあり、アプリとは別に保存されているので、アップデートしても消えません。念のため、更新前に設定画面の「情報」→「エクスポート」でバックアップを取ることをおすすめします。

- 「ログイン時に自動で常駐」をオンにしている場合は、**`clp.exe` の置き場所を変えると自動起動が効かなくなります**。新しい場所から起動して、設定画面でスイッチを入れ直してください。
- アンインストールは、インストーラ版は「設定 → アプリ」から、単体版はファイルを削除するだけです。データを完全に消したい場合は、上記のデータフォルダも削除してください。

## 使い方

1. `clp.exe` を起動すると、タスクトレイに常駐します。
2. **`Ctrl+Alt+V`**（macOS は `⌃⌥V`。変更可）で窓を開きます。
3. 項目を選んで **`Enter`** を押すと、直前に使っていたアプリへ貼り付けて閉じます。

トレイアイコンは左クリックで窓を開き、右クリックで「表示 / snippets.toml を開く / 設定… / 終了」のメニューを出します。

### キー操作

| 動作 | Windows | macOS |
|---|---|---|
| 呼び出し（既定・変更可） | `Ctrl+Alt+V` | `⌃⌥V` |
| 選択移動 | `↑` `↓` / `Ctrl+J` `Ctrl+K` | `↑` `↓` / `⌃J` `⌃K` |
| 貼り付けて閉じる（IME変換中は無効） | `Enter` | `↩` |
| 履歴 ⇔ 定型文 の切り替え | `Tab` | `Tab` |
| 上から1〜10番目を即貼り付け（`0`が10番目） | `Alt+数字` | `⌥数字` |
| 定型文タブで検索欄が空のとき、即貼り付け | 数字キー単体 | 数字キー単体 |
| ピン留めの切り替え（履歴） | `Ctrl+P` | `⌃P` |
| 履歴を削除（`Delete`は検索欄が空のとき） | `Ctrl+D` / `Delete` | `⌃D` / `⌦` |
| `snippets.toml` を開く（定型文タブ） | `Ctrl+E` | `⌃E` |
| 検索欄をクリア → もう一度で閉じる | `Esc` | `Esc` |

macOS の修飾キーは、`⌃` = Control、`⌥` = Option、`⇧` = Shift、`⌘` = Command です。
画面上の表示も、OS に合わせて自動で切り替わります。

検索はスペース区切りで AND 検索です。全角/半角、大文字/小文字、ひらがな/カタカナの違いは区別しません。

## 定型文

設定画面の「定型文」ページで、追加・編集・並べ替え・複製・削除ができます（自動保存、最大30個）。
`%APPDATA%\clp\snippets.toml` を直接編集することもできます。

```toml
[[snippet]]
title = "挨拶"
body = "お世話になっております。"

[[snippet]]
title = "署名"
body = """
--
氏名
"""
```

本文で使える変数:

| 変数 | 展開結果 |
|---|---|
| `{date}` | `2026-11-21` |
| `{time}` | `14:05` |
| `{datetime}` | `2026-11-21 14:05` |
| `{clipboard}` | 貼り付け時点のクリップボードの内容 |

## 設定

トレイの「設定…」から変更できます。

- **一般**: ホットキー、表示位置（画面中央 / マウス位置 / 入力カーソル付近）、Windows 起動時の自動常駐
- **外観**: テーマ（自動・ライト7種・ダーク3種）
- **定型文**: エディタ
- **履歴**: 最大件数（既定3000）、1件の最大サイズ（既定1024KB）、履歴の全削除（ピン留めは残る）

### 設定のバックアップ（エクスポート / インポート）

設定画面の「情報」から、ホットキー・テーマ・表示位置・履歴の上限・定型文を1つの JSON ファイル（`clp-settings.json`）に書き出し、別の PC で読み込めます。履歴の中身は機密を含みうるため、含まれません。

入力カーソル付近は、カーソル位置を取得できないアプリ（Chrome、VS Code など）ではマウス位置に表示されます。

## データの場所

`%APPDATA%\clp\`

| ファイル | 内容 |
|---|---|
| `history.db` | 履歴（SQLite） |
| `snippets.toml` | 定型文 |
| `config.toml` | 設定 |

## プライバシー

- パスワードマネージャーなどが付ける「履歴に残さない」フラグ付きのコピーは保存しません。
- 履歴は **平文** で `history.db` に保存されます。機密情報をコピーした場合は、設定画面から削除してください。
- 通信は一切行いません。

## ビルド

必要なもの: Rust（MSVC ツールチェーン）、Node.js、Visual Studio Build Tools（C++）、WebView2。

```powershell
npm install
npx tauri build --no-bundle
```

出力: `src-tauri\target\release\clp.exe`

開発時は `npx tauri dev`。

### 構成

```
src/            フロントエンド（index.html / settings.html / main.js / themes.js / style.css）
src-tauri/src/
  lib.rs        コマンド、トレイ、ホットキー、クリップボード監視
  store.rs      履歴ストア（SQLite + メモリ検索）
  snippets.rs   定型文の読み書き・変数展開
  platform_win.rs   Windows 依存部分（前面ウィンドウ復帰、キー送信、キャレット位置、自動起動）
  platform_mac.rs   macOS 依存部分（NSPasteboard、NSWorkspace、CGEvent、LaunchAgent）
```

OS 依存の処理は `platform_*.rs` に集約しており、同名の関数群を OS ごとに実装しています。

## macOS について

Mac 版のコード（`src-tauri/src/platform_mac.rs`）は書いてありますが、開発を Windows で行ったため **Mac でのビルド・動作は未検証** です。初回ビルドでエラーが出たら、`objc2` / `core-graphics` クレートのバージョン差による API 違いが原因の可能性が高いです。

Mac でビルドする手順:

```sh
xcode-select --install          # Xcode コマンドラインツール
npm install
npx tauri build                 # src-tauri/target/release/bundle/ に .app と .dmg
```

- **アクセシビリティ権限**: 自動貼り付け（Cmd+V の送信）に必要です。初回起動時にシステム設定が開くので、「プライバシーとセキュリティ → アクセシビリティ」で clp を許可してください。再ビルドすると許可が外れることがあります。
- **Dock には出ません**。メニューバー（トレイ）に常駐します。
- **ホットキー**: 既定は `⌃⌥V`（Control+Option+V）です。設定画面では `⌘` `⌥` `⌃` `⇧` の記号で表示されます。
- **即貼り**: `⌥数字`（Option+数字）です。
- **入力カーソル付近への表示は未対応**です（選んだ場合はマウス位置に表示）。
- **自動起動**は `~/Library/LaunchAgents/local.clp.app.plist` で行います。
- データの場所は `~/Library/Application Support/clp/` です。
- 配布する場合は Apple Developer への登録（年 $99）、署名、公証が必要です。自分用なら不要で、初回は右クリック →「開く」で起動します。
- 透過ウィンドウのために macOS のプライベート API（`macOSPrivateApi`）を使っているため、Mac App Store には出せません。

## リリース手順（開発者向け）

`v` で始まるタグを push すると、GitHub Actions が Windows / macOS 版をビルドし、Releases に自動で載せます。
同時に、アプリ内アップデート用の `latest.json` と署名ファイルも公開されます。

### 初回だけ必要な設定（アップデート署名鍵）

アプリ内アップデートは、署名鍵で更新ファイルを検証します。

1. 鍵を作る: `npx tauri signer generate -w ~/.tauri/clp.key`
2. 公開鍵（`clp.key.pub` の中身）を `src-tauri/tauri.conf.json` の `plugins.updater.pubkey` に入れる（設定済み）
3. 秘密鍵とパスワードを、リポジトリの Secrets に登録する
   - `TAURI_SIGNING_PRIVATE_KEY`: `clp.key` の中身
   - `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`: 鍵のパスワード

**秘密鍵とパスワードを失うと、既にインストールされた clp は更新できなくなります。** 安全な場所にバックアップしてください。また、秘密鍵はリポジトリに含めないでください。

### 版を出す

1. `src-tauri/tauri.conf.json` と `src-tauri/Cargo.toml` の `version` を上げる（`latest.json` の版はここから決まります）
2. コミットして push する
3. タグを打って push する

```sh
git tag v0.2.0
git push origin v0.2.0
```

## トラブルシューティング

### macOS: 「“clp”は壊れているため開けません」と出る

Apple の署名・公証を受けていないアプリをブラウザでダウンロードすると、Gatekeeper がこのメッセージを出すことがあります。ファイルが本当に壊れているわけではありません。
**「ゴミ箱に入れる」は押さず「キャンセル」** にして、ターミナルで次を実行してください。

```sh
xattr -cr /Applications/clp.app
```

（ダウンロード時に付く「隔離」の印を外すコマンドです。`clp.app` を置いた場所に合わせてパスを変えてください。）その後もう一度開きます。

v0.1.1 以降は、アプリに ad-hoc 署名を付けているため、メッセージが「開発元を確認できません」に変わることがあります。その場合は次のどちらかで開けます。

- `clp.app` を右クリック →「開く」→「開く」
- 「システム設定 → プライバシーとセキュリティ」を開き、下の方の「このまま開く」を押す

初回だけの操作です。アプリ内アップデートで更新した版には、この警告は出ません。

## 注意事項

- コード署名をしていないため、他の PC へブラウザ等で配布すると SmartScreen の警告が出ます。「詳細情報」→「実行」で起動するか、ファイルのプロパティで「ブロックの解除」をしてください。
- 管理者権限で動いているアプリへは、通常権限の clp からは貼り付けできません。
- ホットキー・キー送信・クリップボード監視を使うため、ウイルス対策ソフトが誤検知する場合があります。
